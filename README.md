# 💼 Personal Portfolio Website

Welcome to my Personal Portfolio Website! 👋

This portfolio showcases my skills, projects, and learning journey as an aspiring Front-End Developer. It is designed with a clean, modern, and responsive layout to provide visitors with information about my technical skills and projects.

## ✨ Features

- 🏠 **Home Section** – Introduction and welcome message.
- 👩‍💻 **About Me** – Information about my background and career goals.
- 🛠️ **Skills Section** – Displays my technical skills.
- 🚀 **Projects Section** – Showcases my web development projects.
- 📩 **Contact Section** – Allows visitors to connect with me.
- 📱 **Responsive Design** – Supports different screen sizes.
- 🎨 **Modern UI** – Attractive styling, colors, and smooth transitions.

## 🛠️ Technologies Used

- **HTML5** – For website structure.
- **CSS3** – For styling, layouts, animations, and responsiveness.
- **JavaScript** – For interactive features.

## 🚀 How to Run the Project

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Check that all files and images are in the correct locations.
4. Open `index.html` in your browser.
5. Explore the portfolio website.
